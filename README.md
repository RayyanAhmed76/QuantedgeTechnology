# Fello Clone

A pixel-close **React + Vite** clone of [fello.agency](https://www.fello.agency/) — a tech marketing agency landing page.

## Tech stack
- **React 18**
- **Vite 5**
- Plain CSS (custom properties, Flexbox/Grid)
- Inter font (Google Fonts)
- IntersectionObserver-based scroll-reveal + count-up animations

## Sections
Header · Hero · Clients · Work · Why choose us · Services · About · Testimonials · FAQ · Blog · Contact form · Footer

## Getting started
```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # production build -> dist/
npm run preview  # preview the build
```

## Notes
The original hero and project photography are proprietary, signed assets, so the visuals here are recreated with CSS gradients. Drop real images into `public/` and wire them up if you have licensed copies.
